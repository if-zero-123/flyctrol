# NAZE32 飞控调试上位机

这是给当前固件配套的 Windows 图形调试工具。它复用飞控 `USART1` 的文本 CLI，不需要修改固件协议。

## 接线

```text
USB-TTL RX  -> 飞控 PA9
USB-TTL TX  -> 飞控 PA10
USB-TTL GND -> 飞控 GND
```

不要接 `PA2/PA3`，那是 CRSF 接收机口。

## 启动

双击：

```text
tools\flight_debug_gui\run_debug_gui.bat
```

第一次启动如果缺少 `pyserial`，脚本会自动安装。窗口里默认有一个 `FAKE - 无硬件演示` 端口，可以先练习界面；接上 USB-TTL 后点击“刷新”，选择真实 `COMx` 后连接。

如果不知道哪个 COM 是飞控，点击 `自动探测`。上位机会逐个打开真实 COM 口，等待 `hb tick=...`，并尝试发送 `help/status`。

## 推荐调试顺序

1. `连接/日志`：连接串口后等几秒，确认看到每秒一次的 `hb tick=...`；不用抢复位时机。
2. `自检`：点击“一键自检”，确认 I2C、IMU、BARO、RC、电池、安全状态。
3. `实时监控`：点击“开始轮询”，移动飞控并拨动遥控器看数值变化。
4. `电机测试`：必须先拆桨并勾选确认，再用低占空比测试 M1-M4。
5. `首飞检查`：逐项确认后保存检查报告。

## 安全

电机页的 `STOP ALL` 会发送 `motor stop` 和 `motors 0`。程序关闭和断开串口时也会尝试发送停机命令。
